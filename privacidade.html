Política de privacidade do Mark

Última atualização: 3 de novembro de 2026.

O Mark é um aplicativo de uso pessoal. Ele roda apenas no computador do seu dono e só acessa as contas do próprio dono.

Que dados o Mark acessa

Com a autorização dada na tela de login do Google, o Mark usa a API do YouTube para: enviar vídeos, capas, títulos, descrições e tags para os canais do dono; e ler as estatísticas públicas desses vídeos e canais (visualizações, curtidas, comentários e inscritos).

Onde os dados ficam

As credenciais de acesso e os dados dos vídeos ficam guardados somente no computador do dono. O Mark não envia esses dados para servidores próprios nem para terceiros, além das próprias APIs do Google necessárias para cada ação.

Compartilhamento

O Mark não vende, não aluga e não compartilha dados com ninguém. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions. Depois disso, o Mark não consegue mais publicar nem ler dados da conta.

Contato

Dúvidas: pelo e-mail de contato informado na tela de consentimento do Google.
